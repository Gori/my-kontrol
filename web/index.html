This browser can't talk to USB devices

Installing firmware needs WebUSB, which only Chrome, Edge and Opera on a computer have. Open this page in one of them. Safari and Firefox don't support it, and neither do phones.

Connect your keyboard

  1. Plug the M32 into this computer with its USB cable, directly rather than through a hub.
  2. Quit Komplete Kontrol, Native Access, your DAW and any other music app.
  3. Click Connect, pick your keyboard in the list (Komplete Kontrol M32, or My Kontrol M32 once installed), then click Connect in that box.

What do you want to install?

M32

Komplete Kontrol M32

Your keyboard is in update mode and waiting for firmware. That's normal after an interrupted update. Pick something to install and it will start right away.

Firmware

Open an issue on GitHub

Download the M32 firmware updater for Mac from Native Instruments (it's a zip such as KKM_FWUpdater_3.17.0_Mac.zip; the Mac file works on any computer). Don't unzip it, just drop it here. The firmware is read from the file on this computer and nothing is uploaded.

Drop the updater zip here or click to choose a file (.zip or NI .bin)
Advanced: choose the NI firmware type

Each M32 hardware type needs its own NI firmware. The type is picked for you; change it only if you know your keyboard needs the other one.
